# 🤖 Basic ML Projects

This repository contains my beginner-level Machine Learning projects and practice exercises as I learn the fundamentals of Machine Learning.

I am using this repository to document my progress through hands-on practice and gradually build more practical Machine Learning projects.

## 📂 Projects

### 🌸 Iris Flower Classification

My first Machine Learning classification project using a **Decision Tree Classifier**.

The model predicts the species of an iris flower based on its sepal and petal measurements.

**Topics covered:**

* Exploring a dataset
* Features and target
* Model training
* Making predictions
* Decision Tree visualization

---

### 🍎🍊 Apple vs Orange Classifier

A simple beginner-level practice exercise created while learning the basics of **classification and Decision Trees**.

The model learns to distinguish between an apple and an orange using simple input features.

**Topics practiced:**

* Creating a small dataset
* Features and labels
* Training a Decision Tree
* Making predictions
* Decision Tree visualization
